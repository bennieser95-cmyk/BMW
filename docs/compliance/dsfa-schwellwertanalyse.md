# Vorlage: DSFA-Schwellenwertanalyse

**Status: auszufüllen.** Die Bewertung trifft ausschließlich die/der
Datenschutzbeauftragte bzw. die verantwortliche Stelle. Diese Vorlage ersetzt
keine DSFA und keine Rechtsberatung.

| Prüffrage                                                                                      | Ja/Nein/offen | Begründung / Evidenz / Maßnahme                                     |
| ---------------------------------------------------------------------------------------------- | ------------- | ------------------------------------------------------------------- |
| Werden Daten in großem Umfang oder über längere Zeit systematisch überwacht?                   | Offen         | `[Tracking-/RUM-/Analytics-Konfiguration prüfen; Consent beachten]` |
| Werden besondere Kategorien personenbezogener Daten verarbeitet?                               | Offen         | `[Formularfelder und Auth-Dateninventar prüfen]`                    |
| Werden Personen systematisch bewertet/profiliert oder automatisierte Entscheidungen getroffen? | Offen         | `[Fachprozess prüfen]`                                              |
| Werden Daten aus mehreren Quellen zusammengeführt oder umfangreich verknüpft?                  | Offen         | `[Datenflüsse dokumentieren]`                                       |
| Sind schutzbedürftige Personen oder besonders sensible Kontexte betroffen?                     | Offen         | `[Zielgruppe/Prozess bewerten]`                                     |
| Ist neue/innovative Technologie mit hohem Risiko im Einsatz?                                   | Offen         | `[Neon Auth Beta, RUM/Analytics und Plattformintegration bewerten]` |
| Kann ein Vorfall voraussichtlich erhebliche Folgen für Betroffene haben?                       | Offen         | `[Bedrohungs- und Auswirkungsanalyse]`                              |

**Ergebnis der Schwellenwertprüfung:** `[DSFA erforderlich / nicht erforderlich /
Entscheidung offen]`  
**Begründung / Restrisiko:** `[ausfüllen]`  
**Konsultation / Freigabe DPO:** `[Name, Datum, Nachweis]`  
**Review-Auslöser:** neue Zwecke/Datenfelder, neue Analytics, wesentliche
Änderung der Auth-/Lead-Verarbeitung, neue Empfänger oder erheblicher
Sicherheitsvorfall.
